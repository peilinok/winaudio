## 固定条件

机器、电源、显示、客户区、日志和信号沿用 charts-baseline-report.md 与 machine.json。CABLE Input 端点为 `{0.0.0.00000000}.{09793ccf-e246-4dbf-800b-a7cf44856994}`，实际 48000 Hz／8ch；两个生产 RenderTrack 的 Channel ident 分别为 65%／25% 音量。FFT 2048、Hop 1024、追赶上限 8、每声道 491520 样本、声谱 128×480 全部保持不变，离屏展开 Host 继续维护 CPU 历史。

每轮预热 30 秒、观察 120 秒；双 Track 四阶段各 30 秒，单 Track 两阶段各 60 秒。过渡帧、预热和 teardown 单列。正式采样期间未编译、运行测试或其他性能负载，只进行代码／文档阅读、编辑及只读评审。

采样程序 SHA256 为 `DB67DB7700A43722CA31EEA7F0FE83D869C91B6895376DFE576627A0D14D98C4`。config.json 中的 source 为启动脚本时的 HEAD `20d3ea7`，当时另包含随后提交为 `d829c6d` 的 Inspector 接线；图表生产与测试驱动源码仍与 `20d3ea7` 一致。该二进制的 AppUi 不含 d829c6d 最后补的“空列表显示 pump 失效提示”分支，此差异仅触达 Inspector。不能将随后修改的查询／导出源码当成这次二进制。

## 内存与分项成本

波形暂存由 AppUi 共用一个可复用工作区，顺序为当前来源的全部声道读取成功后一起提交。八声道完整历史的样本载荷上界为 `8×491520×4=15728640` 字节，即 15 MiB；不为每条 Track 再常驻一套完整事务暂存。实际正式三轮双 Track 的暂存容量峰值分别为 1152000、1336320、1182720 字节，来自逐帧容量最大值；线性历史仍承担每次推进时的搬移。长冻结恢复可能请求完整历史，不能把稳态小容量当作永远只需约 1 MiB。

第一轮双 Track 的 wave 阶段，Chart Refresh p95 约 4.01～4.03 ms、可见波形包络约 1.70～1.72 ms；FFT 约 0.72～0.73 ms、声谱历史推进约 0.34 ms。spec 阶段 Chart Refresh 约 4.13～4.15 ms、着色约 0.29 ms、上传命令约 0.05 ms。FFT／历史属于刷新，包络和上传也分别嵌套于界面生成，不能把这些分位数直接相加。GPU 完成耗时没有用 UpdateSubresource 的调用时间代替。

块索引仍在波形内容变化后重建；无新增或冻结时同 generation／revision 复用。可见曲线仍按视窗生成，本轮没有添加最终曲线缓存。声谱 CPU 历史和 GPU 纹理按来源／方向／声道独占、首次可见惰性分配：一张 128×480 RGBA 的 CPU／GPU 样本载荷各 245760 字节，十六张各约 3.75 MiB；实际驱动分配和进程内存见逐轮 CSV，不能把这个载荷计算当成进程总开销。
