## 真实会话与探针干扰

两个新建同位数目标使用真实 render／loopback，登记 PID、实际载入 DLL 路径和 SHA256。pump 默认关闭的十分钟与后续二十秒开启分开。控制环覆盖、pump xrun、真实 API 失败、discontinuity 与计时蓄水池溢出分别解释。连续目标在 Attach 前已经 Initialize，不能用低速会话证明新的 Initialize 图字段或代替固定一万条场景。

本次目标为 x64 HookAudioProbe PID 4228／27980，实际端点 `{0.0.0.00000000}.{46f4256f-bc60-4865-b5f3-4c6eef7ee966}`，48000 Hz／2ch／32-bit。实际加载 `build/performance-vs18/bin/Release/WinAudioHook-5.dll`，SHA256 为 `3964B5CF4B029D7C601D53CD3FA688068A895D690B256BDA87389C0A112C49F3`。路径与散列登记在该轮 config.json，未用历史 Hook 报告的旧二进制冒充。

## 行为、停止条件与限制

真实 GUI 与确定性边界详见 [GUI 行为记录](gui-checks/README.md) 和 [实施取舍](inspector-implementation-notes.md)。生产窗口已验证多 PID、Detach／重连、三种替换决定、Attach 失败保留、空录制与子集保存、pump 选择失效；两份真实 JSONL 随证据归档。受控 writer 延长首次后台 write 至六十秒，经真实主循环检查忙／继续浏览、普通取消、退出等待／取消、保存失败保留，以及真实双 PID 接收期间冻结三十条而历史增至七十八条。受控 writer 不创建真实文件，不冒称磁盘故障实验或正式保存性能；文件各阶段失败和 CSV 另由确定性测试覆盖。

达到主线程 8／16 ms、每种操作 p95≤100 ms 和固定历史内存稳定后停止扩大。增量排序、归档／数据库／分页、十万条及数小时会话保持延期；没有为追求额外数字而扩展本轮。
