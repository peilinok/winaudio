# 每段最近 1024 条调用与源端累计统计验收

本票为 #260，基线为 `cbd80d307a0bc0971651d93d862f49703fc1eae5`，分支 `feat/segment-window-stats`。范围以 #252 父规格、#260 验收条件及已关闭的 #258／#259 输出为准。清空、导出、批量附加、启动产品入口和正式性能验收由后续票分别交付。

## 实现与所有权

- WinAudio 为每个 PID 的每个附加记录段保留最近 1024 条完整接收的窗口调用。全部 12 个默认关闭的方法共用该段容量；控制历史独立。已结束段保留窗口、最后源端统计及实际快照时点，新段空窗口、零累计，迟到旧段更新被拒绝。
- 目标仍只有 2048 槽控制传输、64 槽高频传输及固定方法计数，不增加目标浏览窗口。WinAudio 的接收批、接收器近期快照、活动段窗口和控制器队列各有固定边界；控制历史及用户要求保留的历史段可有意增长，不承诺全进程内存恒定。
- 共享布局升到 10；`CallPod` 为 1048 字节，`Ring` 为 2265528 字节。新增方法计数位于偏移 2264728，每方法四个对齐的 64 位原子量。高 32 位标识观测代次，低 32 位保存累计或不确定标志。原计数达到 `UINT32_MAX` 后保持下界并标记未知；竞争超过八次也标记未知，不作无界重试。未知标记最多两次 CAS，代次只递增，达到上限拒绝重附加；确定性回归覆盖旧标记先完成／后完成两种顺序。
- 窗口方法从进入时快照取得监控选择及代次。原 API 恰好转发一次，返回后更新完成次数，`FAILED(HRESULT)` 单独增加失败次数。只有 capture GetBuffer 返回 `S_OK`、有效非空包及有效输出 flags 时才统计音频数据不连续；`S_FALSE`、`AUDCLNT_S_BUFFER_EMPTY`、失败及零帧不读取未产生的 flags。计数先于记录准备与提交，与 emit 成功、传输留存及窗口淘汰无关。关闭方法不作受监控计数，开／关与查看切换不清累计。
- 各原子计数不是共同事务，也不与逐条记录同时采样。界面分别显示窗口保留、完整接收入段、窗口淘汰、传输覆盖／拒写／控制器队列缺失、API 失败和有效音频不连续；从累计减窗口或从两个不同时点的差值推算“丢失”均未采用。未知快照与可验证零值明确区分。
- 后台接收线程继续按每 PID 固定预算接收，界面每 100 毫秒最多交接一次展示数据。展示限频不改变源记录时间戳，不在容量到达后停收，也不抽样。窗口维护只遍历窗口，不扫描或复制全部控制历史。

### 调用顺序

窗口按宿主完整接收批次推进。一次有限接收批内按传输 ticket 排序后赋予宿主递增记录身份，避免扫描跨越物理槽尾部时，把该批的较新调用排在较旧调用之前。跨 poll 迟到完成的调用属于后来接收的批次；既不等待所有源端在途调用，也不承诺跨线程全局开始顺序。保留原调用时间戳，界面仍可按原时间显示。完整槽发布及所有权协议继续复用 #259，没有退回两次比较 payload 的提交猜测。

## 双进程完整接收与独立源统计

`SegmentWindowProbe` 使用两个真正的子进程，直接编译并调用生产 Hook 入口、生产共享映射、`PumpWindow` 和 `CallLogStore`。它属于无设备合成跨进程证据，不是 DLL 注入、真实音频或性能证明。目标原函数独立计数，每 17 次仅在探针控制路径握手避免传输容量丢弃；生产 Hook 内没有等待。

每个 PID 完成并完整接收 10013 条，关闭监控期间另原样转发两次，因此独立原调用为 10015。两个 PID 分别选择 `IAudioClock::GetFrequency` 与 `IAudioRenderClient::ReleaseBuffer`。每条 HRESULT／参数均检查，最终逐项验证序号 8990 至 10013 的 1024 条。每 PID 完成累计 10013、失败 910、有效不连续 0，两个控制 Start 各独立保留 1 条；未选择方法累计为零，两个 PID 的覆盖／拒写均为可验证零，目标正常退出码均为 0。归档后拒绝迟到行和快照，同实例新段空窗口、生产新代零统计。

最终各配置完整原始结果见 `final-window-<架构>-<配置>.json`；包含 PID／创建时间、结构 ABI、指针位数、完整接收数、逐项检查数、独立原调用与源计数、初始零、冻结历史、新段及实际退出码。原有四生产者覆盖、持槽、拒写、回绕和未知路径通过 `HookTransportProbe` 另行复验，不把其尝试数当成本票完整接收数。

最早的 32 条节拍首跑 `segment-window-x64-debug-first.json` 各 10016 条虽通过，未覆盖非整除槽尾，故仅保留为历史证据；最终验收以 17 条节拍和上述非整除回归为准。
